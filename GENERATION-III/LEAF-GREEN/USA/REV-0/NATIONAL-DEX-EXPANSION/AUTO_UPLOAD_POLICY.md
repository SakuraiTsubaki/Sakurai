# GitHub auto-upload policy — LeafGreen National Dex Expansion

## Repository routing

- `SakuraiTsubaki/Sakurai`: analysis, audits, reports, verification logs, design documents, machine-readable research JSON/CSV.
- `SakuraiTsubaki/Tsubaki`: builders, patch-generation source, manifests, reusable assets, converted resources, and other reproducible work assets.

## Canonical hierarchy

`GENERATION-III/LEAF-GREEN/<REGION>/REV-0/NATIONAL-DEX-EXPANSION/<work>`

Current source ROM regions are USA (`BPGE`, Rev 0) and JPN (`BPGJ`, Rev 0).

## Never upload

- Original `.gba` ROMs.
- Modified `.gba` ROMs.
- Save files or copyrighted binary extracts that would substitute for the original game.

Only safely redistributable project outputs are committed.
