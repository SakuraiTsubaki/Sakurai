# Pokémon LeafGreen National Dex Expansion — USA

Target ROM family: **USA BPGE Rev 0**. The original ROM remains read-only and is never committed.

## Scope

- National species: 1025
- battle varieties: 1351
- visual/form records: 1579
- reserve base Species IDs through 2047 for Generation 10+

## Current phase

Original-ROM engine/data-limit audit and ID-architecture work. The current work is not a finished 1025-species playable ROM.

## Repository split

Research and audits live in `Sakurai`; builders/manifests/reusable build assets live in `Tsubaki`, using the same Generation/Game/Region/Revision/Work hierarchy. ROM binaries are excluded from both repositories.
