# Coverage contract

* ROM size: 0x80000 bytes.
* Bank size: 0x4000 bytes.
* Banks: 0x00–0x1F.
* Page size: 0x100 bytes.
* Pages: 2048 per ROM.
* Bank 0 maps to CPU 0000–3FFF; switchable banks map to 4000–7FFF.
* The page manifest covers the ROM consecutively from file offset 0x00000 through 0x7FFFF.
* No original ROM bytes or split bank binaries are distributed in this package.
