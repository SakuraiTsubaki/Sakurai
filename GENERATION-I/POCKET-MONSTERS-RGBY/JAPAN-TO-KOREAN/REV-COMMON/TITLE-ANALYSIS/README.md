# Generation I Korean title family

Approved title family:

- 포켓몬스터 레드
- 포켓몬스터 그린
- 포켓몬스터 블루
- 포켓몬스터 피카츄

## Fixed design rules

- Use the official GS Korean `포켓몬스터` title artwork as the common visual/technical reference.
- Preserve the common logo exactly, including the final `터`.
- Version-name lettering uses actual GS Korean Hangul glyph silhouettes.
- Approved treatment is **B**: exterior-only dark outline plus top/left highlight.
- Do not redraw Hangul strokes in ways that reduce legibility.
- Do not use AI image generation for ROM title assets.
- Actual per-ROM tile/VRAM/animation insertion remains a separate validation step.

## Storage

Final reusable title assets are stored in `SakuraiTsubaki/Tsubaki` under each Generation I game path.
No ROM binaries are stored in GitHub.
