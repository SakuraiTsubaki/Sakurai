# Sakurai

Pokémon ROM identity, reverse engineering, comparison, localization research, technical design, and verification repository.

## Canonical path model: v7

```text
GEN-XX/<GAME-ID>/SOURCE/<PLATFORM-ID>/<PACKAGE-KIND>/<RELEASE-ID>/...
GEN-XX/<GAME-ID>/COMPARE/<COMPARISON-ID>/...
GEN-XX/<GAME-ID>/SHARED/...
GEN-XX/<GAME-ID>/REFERENCE/<REFERENCE-ID>/...
GEN-XX/TARGET/<TARGET-ID>/...
GEN-XX/COMPARE/<COMPARISON-ID>/...
GEN-XX/SHARED/...
GEN-XX/REFERENCE/<REFERENCE-ID>/...
CROSS-GEN/TARGET|COMPARE|SHARED|REFERENCE/...
INFRA/...
```

v7 is generation-first. The former top-level `LIBRARY/` and `PROJECTS/` split is retired: official-source research and derived targets now live under the same generation owner while remaining explicitly separated by `SOURCE` and `TARGET`.

`RELEASE-ID` identifies an official software/build identity. `DUMP-ID` identifies one exact observed image beneath that release. Platform, package, language, market, revision, product/title ID, hashes, and provenance are recorded in manifests; human locale labels never replace stronger native technical identity.

Sakurai is authoritative for release/dump identity, ROM structure, pointers, text/data/code research, comparisons, source crosswalks, design specifications, citations, and verification evidence.

Original ROM/executable binaries are never committed.

See `STRUCTURE.md` for the complete grammar and `MIGRATION.md` for the v6 → v7 cutover.
