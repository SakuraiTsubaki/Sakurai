# Sakurai

Pokémon source identity, reverse engineering, comparison, localization research, technical design, and verification repository.

## Canonical path architecture: v9 proposal

```text
GAMES/GEN-XX/<GAME-ID>/RELEASES/<RELEASE-ID>/...
GAMES/GEN-XX/<GAME-ID>/TARGETS/<TARGET-ID>/...
GAMES/GEN-XX/<GAME-ID>/COMPARES/<COMPARISON-ID>/...
GAMES/GEN-XX/<GAME-ID>/REFERENCES/<REFERENCE-ID>/...

SCOPES/GEN-XX/TARGETS|COMPARES|REFERENCES|SHARED/...
SCOPES/CROSS-GEN/TARGETS|COMPARES|REFERENCES|SHARED/...

REGISTRY/...
INFRA/...
ARCHIVE/PRE-V9/...
```

v9 removes platform/package/language/region/revision directory layers from canonical ownership paths. Those facts remain explicit manifest data. Release and project ownership is determined by stable registered IDs, not transport metadata.

Sakurai owns release identity, ROM/native structure, hashes, offsets, code/pointer/table research, text/data/event/map/system analysis, comparisons, localization research, crosswalks, technical specifications, citations, and verification evidence.

Tsubaki owns extracted/converted production assets, normalization, implementation helpers, patches, build recipes, and production verification. Dedicated implementation repositories remain canonical for their engine source and are referenced by exact commit instead of mirrored wholesale.

Original or modified full ROM/executable binaries are never committed.

See `STRUCTURE.md` and `MIGRATION.md`.
