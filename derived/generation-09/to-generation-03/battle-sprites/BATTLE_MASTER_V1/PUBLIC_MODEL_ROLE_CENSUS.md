# Generation IX → Generation III Battle Sprite Master v1 — Public Model-Role Census

Research date: **2026-09-15**

Status: **First exhaustive public configuration census complete; game-native catalog crosswalk pending.**

## Purpose

This census exhaustively parses the public Generation IX model configuration trees exposed by `freedom12/PokemonModelViewer` at pinned commit:

`c5952930343748e6dcb4cae21ee383e0bd13b75c`

It is used to discover model-resource roles, icon references, and animation coverage before canonical battle-sprite source selection.

It is **not** treated as the retail game's authoritative `poke_resource_table.trpmcatalog`.

## Critical semantic rule

The public source names the two suffix fields:

- `formIndex`
- `variantIndex`

and generates them directly from model-directory identifiers of the form:

`pmXXXX_YY_ZZ`

Therefore this project preserves them exactly as:

- `config_form_index`
- `config_variant_index`

They are **not** renamed to `game_form` or `game_gender` without proof.

The game-native catalog parser evidence separately establishes an authoritative key shaped as:

`(species, form, gender)`

The next crosswalk phase must determine how each public directory/config role maps to those native fields.

## Internal-number warning

Some public model configuration numeric IDs exceed the currently established National Pokédex range.

Therefore the `number` field in this public census is treated as a **public resource/config numeric identifier**, not automatically as a National Pokédex number.

No record receives a National Pokédex identity until independently cross-checked against game-native or equivalent authoritative data.

## Source integrity

The workflow records:

- pinned upstream repository and commit
- upstream `index.json` SHA-256
- deterministic combined config-tree SHA-256
- SHA-256 of every parsed per-ID JSON config
- CSV resource-role rows
- animation-name-set SHA-256 per resource role

Thus any later change in the public source can be compared rather than silently replacing the current census.

## What this census proves

It proves that the selected pinned public configuration source contains the recorded model-resource IDs, suffix indices, icon references, and animation inventories.

It does **not** prove by itself:

- official National Pokédex identity for every numeric ID
- official semantic meaning of every suffix index
- Scarlet/Violet retail-catalog completeness
- Z-A retail-catalog completeness
- normal/shiny material mapping
- final front/back battle pose selection
- canonical source approval for Generation III conversion
