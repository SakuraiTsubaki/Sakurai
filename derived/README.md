# Derived Cross-Repository Work

This namespace contains Sakurai research/control material whose owner is the **combined Disassembly + Decompilation corpus**, not one upstream repository.

Examples include:

- cross-generation comparisons
- cross-series format studies
- consolidated terminology or identity tables
- analyses derived from multiple upstream repositories
- repository-wide verification or provenance studies

Every derived item must cite or otherwise identify its contributing upstream repositories.

Do not use this namespace as a dumping ground for material whose exact upstream owner is already known.
