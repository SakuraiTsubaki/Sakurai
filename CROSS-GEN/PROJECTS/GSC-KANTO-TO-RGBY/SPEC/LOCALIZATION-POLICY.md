# Localization policy

## Official terminology

For every supported language, use the latest official terminology available for Pokémon names, moves, items, locations, facilities, UI terms, and other named concepts unless a technical compatibility exception is documented.

## Proofreading

All localized text is proofread according to the orthography, grammar, punctuation, spacing, register, and typography conventions of the target language. Do not preserve an older translation error solely for nostalgia when the project rule calls for current official naming.

## NPC voice and dialect

NPC speech should reflect the dialect or regional speech associated with the real-world area that inspired the corresponding in-game locality, adapted naturally to each target language. Dialect is a characterization layer, not an excuse to reduce clarity or introduce caricature.

## Pokédex text

Pokédex descriptions use the latest appropriate official description for each supported language where the project has chosen a modernized description policy. Any exceptions required by screen, encoding, or engine limits must be documented and reviewed rather than silently truncating meaning.

## Technical fit

Modern terminology and dialect choices still have to fit Generation I text encoding, box widths, control codes, and storage constraints. When text must be shortened, preserve official naming and semantic meaning first, then adjust phrasing while recording the constraint.
