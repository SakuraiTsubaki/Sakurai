## Migration rule

`INFRA/MIGRATION/` is historical evidence only. A current Generation V artifact must not exist only in migration quarantine when it has an unambiguous canonical owner.

Complete playable ROM images are excluded from GitHub. Other project artifacts belong in their canonical active paths.
