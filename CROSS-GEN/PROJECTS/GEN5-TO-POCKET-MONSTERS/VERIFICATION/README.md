# VERIFICATION

Verification is project-owned evidence comparing source behavior/data against target behavior/data.

Required scopes include: ROM identity lock, source extraction reproducibility, target baseline reproducibility, data crosswalk completeness, battle interaction regression, map/event/save regression, UI/graphics/audio validation, communication fallback validation, and unused-content normalization safety.

Do not treat 'boots' or 'runs' as completion. Every implemented domain should record normal cases, edge cases, save/reload behavior, version-specific behavior, and source-vs-target parity or intentional divergence.
