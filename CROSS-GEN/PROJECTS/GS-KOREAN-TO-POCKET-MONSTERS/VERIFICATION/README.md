# Verification

Verification evidence belongs here when it validates the cross-generation project rather than one official source release.

Minimum gates:

- 23/23 source images match the locked SHA-1 identities.
- source header/global checksum results remain recorded.
- no project target is represented as an official source release.
- JP and EN source differences remain independent.
- Korean Gold/Silver implementation comparisons retain release ownership.
- round-trip text encoding, pointer integrity, UI rendering, events, save/name strings, patches, and final build hashes are checked per target.
