# 한국어 현대화 편집 정책

## 기본 원칙

1. 한국어 전체의 맞춤법, 띄어쓰기, 문법, 문장 부호와 오역을 전수 점검한다.
2. 포켓몬, 기술, 도구, 트레이너 분류, 인명, 지명, 시설명과 시스템 용어는 현재 공식 최신 한국어 명칭을 우선한다.
3. 원본 ROM의 구표기는 역사적 source evidence로 보존하지만 target의 기본 표기로 자동 승계하지 않는다.
4. 도감 설명문은 해당 포켓몬이 수록된 최신 정식 한국어판의 공식 도감/설정 문구를 우선한다. 최신 작품에 한국어 도감 문구가 없으면 마지막 공식 한국어 수록판을 기준으로 한다.
5. 용량 부족을 이유로 구판 한국어 문구를 유지하지 않는다. 필요하면 텍스트 재배치, 포인터 재구성 또는 최신 공식 설정을 훼손하지 않는 범위의 축약을 사용한다.
6. 팬 번역, 비공식 설정, 추측과 임의 정보를 공식 사실처럼 추가하지 않는다.
7. 모든 변경 항목은 source string, target string, authoritative source, verification status를 추적한다.
8. Gold와 Silver의 원본 차이는 보존하며, 실제로 동일한 데이터만 비교 검증을 거쳐 공통 처리한다.
9. 원본 ROM과 개조 ROM 이미지는 GitHub에 커밋하지 않는다.

## Phase 2 적용 범위

뱅크 6C에서 추출한 도구명, 트레이너 분류명, 포켓몬명 슬롯, 기술명을 최신 공식 한국어 명칭과 대조한다. 원장의 `latest_official_korean`, 출처와 검증 상태가 채워지기 전까지 해당 행을 target 확정값으로 간주하지 않는다.

다음 단계에서는 뱅크 68–69의 도감 텍스트를 전수 추출한 뒤 같은 출처·검증 원칙으로 최신 공식 한국어 설명문을 적용한다.
