# Translation crosswalks

Crosswalks map each Japanese or English source release independently to modern Korean terminology and final Korean text.

Rules:

- Japanese source text is translated directly from that Japanese release.
- English source text is translated directly from that English release.
- Regional localization differences are preserved.
- Current official Korean names take priority for named entities and system terminology.
- GS Korean text may be consulted, but Gold/Silver Korean is primarily the official technical implementation reference.
