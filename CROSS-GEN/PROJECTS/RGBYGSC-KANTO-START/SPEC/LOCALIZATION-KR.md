# 한국어 현지화 원칙

Status: **canonical project rule**.  
Established in project sessions on 2026-09-04; carried into repository layout v12 on 2026-09-14.

## Core rules

1. 한국어 텍스트는 맞춤법, 띄어쓰기, 문장부호를 교정한다.
2. 공식 한국어 명칭이 존재하면 **항상 최신 공식 한국어 명칭을 우선**한다.
3. 모든 NPC의 말투는 원작에서 해당 지방·지역의 모티브가 된 현실 지역에 대응하는 방언을 사용한다. 일괄적으로 표준어로 평탄화하지 않는다.
4. 구 번역명·팬 번역명과 최신 공식 명칭이 충돌하면 최신 공식 명칭을 기본값으로 삼고, 호환성 때문에 예외가 필요한 경우 그 이유를 기록한다.
5. 현지화 과정에서 이벤트 의미, 캐릭터 성격, 게임 진행 조건과 원본의 정보량을 임의로 삭제하거나 축소하지 않는다.

이 문서는 `RGBY カントー地方 -> GSC` 프로젝트의 KR 작업 전체에 적용한다.
