# RGBYGSC Kanto Start

Generation II engine, Kanto-first new adventure. This target integrates Generation I RGBY Kanto into Generation II GSC Kanto without deleting or shrinking either generation's content.

This Sakurai tree is the evidence/research side of the project. It owns source identities, ROM observations, bank fingerprints, map/event/tileset/sprite research, specifications, comparisons and verification. The production counterpart lives at the same canonical target path in `SakuraiTsubaki/Tsubaki`.

Primary implementation base: Korean Silver `AAXK-HV0` / `PROJECT-cb22d7e0`. Generation I and the other GSC releases are comparison/integration sources, not replacements for that engine anchor.

ROM binaries are never committed.
