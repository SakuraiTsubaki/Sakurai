# RBY ENGLISH → G

Canonical Green-specific project for building a complete English Pokémon Green while preserving Pokémon Green as the content authority.

Direction is fixed: **Red / Blue / Yellow English localization system → Pokémon Green**.

Green maps, events, NPCs, encounters, trainers, item placement, graphics, sprites, balance, battle data, progression and version-specific content remain Green-owned. Red/Blue/Yellow English are official localization/system references, not replacement content ROMs.

Tsubaki stores the complete non-ROM project corpus. Sakurai mirrors the curated research/control subset at the same v11 coordinates.
