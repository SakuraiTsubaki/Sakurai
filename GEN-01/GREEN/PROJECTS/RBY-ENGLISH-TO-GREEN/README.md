# RBY ENGLISH → G

Canonical Green-specific target for building a complete English Pokémon Green while preserving Pokémon Green as the game/content authority.

## Direction

`Red / Blue / Yellow English localization system → Pokémon Green`

This target consumes the generation-level English localization research at `GEN-01/TARGET/RBY-ENGLISH-RELOCALIZATION`, but it is not a Red/Blue conversion. Green maps, events, NPCs, encounters, trainers, item placement, graphics, sprites, balance, battle data, progression and version-specific content remain Green-owned unless a separately documented localization implementation change is required.

## Sakurai responsibility

Sakurai stores the evidence plane for this target: release/dump identity, ROM observations, bank/pointer/text/code/UI research, Green↔R/B/Y comparison matrices, translation provenance, specifications, citations and verification results.

## Tsubaki responsibility

Production assets, conversion outputs, implementation source, patches, build recipes and non-ROM build artifacts live in `SakuraiTsubaki/Tsubaki` under the same target ID.

## ROM policy

Original and modified ROM binaries are never committed. All other project outputs are versioned under their truthful owner.
