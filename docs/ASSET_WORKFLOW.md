# Aggregate Artifact Workflow

Sakurai does not treat every artifact as something to duplicate physically. Its responsibility is the research/control representation of the wider corpus.

1. Record originating repository and project.
2. Assign or reference stable release/project/artifact identity.
3. Preserve provenance, hashes, locators, and verification state.
4. Link to the canonical project artifact rather than creating redundant mirrors when a reference is sufficient.
5. Preserve materially different variants and relationships.
6. Record tools, methods, and evidence needed to reproduce important claims.

Eligible Sakurai research/control material is part of the wider Tsubaki non-ROM superset model.
