# Verification

Aggregate claims should be reproducible and scoped to explicit repositories/projects/targets.

- **Observed** — directly confirmed from repository, release, or artifact evidence.
- **Reproduced** — a documented process recreates the expected aggregate result.
- **Matched** — identity or relationship satisfies an explicit criterion such as commit/hash equality, byte identity, exact metadata, or deterministic comparison.

Record origin, target identity, method, expected result, actual result, and supporting hashes or reports.
