# Roadmap

## Phase 1 — Repository registry
Inventory every Disassembly, Decompilation, and special project repository.

## Phase 2 — Stable identities
Define repository, project, release/build, and artifact IDs without moving canonical project material.

## Phase 3 — Research/control indexes
Aggregate provenance, analysis, specifications, comparisons, and verification records.

## Phase 4 — Relationship model
Connect source/target, related-version, shared-artifact, and cross-generation relationships explicitly.

## Phase 5 — Verification
Add reproducible validation for aggregate identities, references, hashes, and relationship claims.

## Phase 6 — Coverage expansion
Expand the research-control subset as the repository ecosystem grows while keeping one stable live structure.
