# Shared Material

This namespace contains material that is genuinely shared across multiple upstream Disassembly/Decompilation repositories.

Use it only when equivalence has been verified. Similar names, appearance, or behavior are not enough.

Each shared item must retain provenance back to every upstream repository that uses it, ideally through a manifest with hashes and verification notes.

Sakurai uses this namespace for shared research/control records rather than production-only assets.
