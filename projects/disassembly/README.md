# Disassembly Upstreams

This namespace aggregates the **curated Sakurai projection** of all repositories in the Disassembly series.

Each upstream repository gets its own directory using the exact repository name as the namespace key:

```text
projects/disassembly/<UPSTREAM-REPOSITORY>/
```

Current upstream coverage: **12 repositories across Generations I–III**.

Only Sakurai-appropriate material belongs here: identity, provenance, hashes, analysis, comparisons, research documentation, research tooling, manifests, and verification evidence.

Do not flatten two upstream repositories into one directory merely because they target the same game family. Preserve exact upstream identity and record verified sharing through manifests.

See `../../manifests/upstream-repositories.json` for the authoritative repository list.
