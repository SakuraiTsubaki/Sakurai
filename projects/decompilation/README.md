# Decompilation Upstreams

This namespace aggregates the **curated Sakurai projection** of all repositories in the Decompilation series.

Each upstream repository gets its own directory using the exact repository name as the namespace key:

```text
projects/decompilation/<UPSTREAM-REPOSITORY>/
```

Current upstream coverage: **34 repositories across Generations III–X**.

Only Sakurai-appropriate material belongs here: identity, provenance, hashes, analysis, comparisons, research documentation, research tooling, manifests, and verification evidence.

Do not flatten two upstream repositories into one directory merely because they target related games. Preserve exact upstream identity and record verified sharing through manifests.

Generation X repositories are treated cautiously; do not infer unverified platform/build details.

See `../../manifests/upstream-repositories.json` for the authoritative repository list.
