# Sakurai ↔ Tsubaki Pairing

The repositories form a coordinated pair.

## Sakurai
Curated research/control subset: identity, provenance, hashes, analysis, comparisons, localization research, schemas, reports, citations, research tooling, and verification evidence.

## Tsubaki
Complete eligible non-ROM production/archive superset: all project artifacts except complete playable ROM images.

## Pair rules

- Use identical semantic coordinates for the same generation/game/release/dump/project/comparison/reference/target.
- A curated artifact mirrored in both repositories should retain the same identity and provenance.
- Tsubaki may contain many eligible artifacts that do not belong in Sakurai's curated subset.
- Moving a live owner path should be reflected consistently where the same semantic material exists in both repositories.
- Git history is the history; do not create parallel migration trees.
