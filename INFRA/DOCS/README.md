## Working flow

1. Resolve the canonical semantic coordinate and owner path.
2. Record provenance and evidence.
3. Keep hypotheses separate from verified findings.
4. Add only curated research/control material appropriate to Sakurai.
5. Mirror eligible complete project artifacts in Tsubaki when applicable.
6. Update manifests and verification evidence as confidence improves.
