# GREEN artifact ownership

Canonical identity is shared between Sakurai and Tsubaki.

- Sakurai owns release/dump identity, ROM layout, reverse engineering, text/data research, comparisons, source validation and verification evidence.
- Tsubaki owns production extraction manifests, converted graphics/audio/UI resources, deduplicated named assets, target implementation inputs, patches and build outputs.
- Original ROM binaries and undifferentiated copyrighted ROM chunks are never committed.
- `JP-JA-HV0` and `JP-JA-HV1` always mean the same official GREEN releases in both repositories.
- Cross-revision equality is promoted to shared production only at verified named asset boundaries; bank or fixed-size block equality is merely a hint.
