# Tsubaki Complete Non-ROM Policy

Status: **mandatory** — 2026-09-13.

For Pokémon ROM projects, Tsubaki is the complete project artifact repository.

**Exclude only ROM images and equivalent lossless whole-ROM payloads.** Everything else produced by project work is in scope for Tsubaki: analysis, research, documentation, manifests, hashes, tables, source code, scripts, schemas, logs, comparisons, extracted assets, fonts, graphics, UI resources, text/translation data, normalized/converted assets, implementation resources, patches, build recipes, and verification evidence.

Sakurai remains the knowledge/control subset. Sakurai content is not a reason to omit the same non-ROM artifact from Tsubaki.
