# Repository Ownership Policy v11

- **Sakurai**: canonical research, release identity, exact-dump observation, reverse engineering, specifications, reports and verification.
- **Tsubaki**: every reproducible project artifact except ROM images. Tsubaki includes synchronized knowledge/evidence plus extracted/normalized/converted assets, implementation source, tools, patches, build metadata, tests and reports.
- **ROM binary exclusion**: original, modified, rebuilt, trimmed, padded or otherwise playable ROM images are never committed.
- **No reconstruction-by-splitting**: a complete ROM may not be disguised as a set of byte chunks.
- **Shared IDs**: both repositories use identical generation, game, platform, package, release and dump IDs.
