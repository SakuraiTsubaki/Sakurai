# Repository Structure v11

Status: **canonical** — 2026-09-13.

v11 keeps the release-centric semantic path grammar introduced by v10, but corrects the repository ownership model.

## Core invariant

**Tsubaki is the complete non-ROM superset. Sakurai is a curated knowledge/research subset.**

Only complete original or modified/playable ROM images are excluded from Tsubaki. Every other project artifact belongs in Tsubaki, including identity/provenance metadata, hashes, observations, analysis, documentation, reverse engineering, schemas, tables, manifests, catalogs, extracted assets, normalized/converted assets, implementation source/data, patches, build recipes and metadata, logs, tests, reports, tools and verification evidence.

Any non-ROM artifact committed to Sakurai MUST also exist in Tsubaki at the same semantic v11 coordinate. Tsubaki may contain additional production/data artifacts that are not mirrored to Sakurai.

```text
GEN-XX/

GEN-XX/<GAME-ID>/
├── RELEASES/
├── PROJECTS/
```

## Release grammar

```text
GEN-XX/<GAME-ID>/RELEASES/<PLATFORM-ID>/<PACKAGE-KIND>/<RELEASE-ID>/
└── DUMPS/<DUMP-ID>/
```

`DUMP-ID` is content-addressed as `DUMP-SHA256-<first-16-uppercase-hex>`. Language, region, market, revision and hashes remain manifest fields.

```text
├── OBSERVATION.json
├── EXTRACTION.plan.json
├── ANALYSIS/
├── CATALOGS/
└── VERIFICATION/
ANALYSIS/
TABLES/
SCHEMAS/

CATALOGS/

ASSETS/
NORMALIZED/
CONVERTED/
IMPLEMENTATION/
PATCHES/
BUILD/
LOGS/
TESTS/
VERIFICATION/
TOOLS/
```

No directory is required when empty. The list is extensible for truthful non-ROM artifact classes.

### Sakurai release leaf — curated subset

Sakurai normally contains the research/control subset:

```text
RELEASE.json
DUMPS/<DUMP-ID>/OBSERVATION.json
ANALYSIS/
TABLES/
SCHEMAS/
REPORTS/
VERIFICATION/
TOOLS/
```

These files are not Sakurai-exclusive: each must also be mirrored in Tsubaki.

## Projects / comparisons / references

```text
GEN-XX/<GAME-ID>/PROJECTS/<PROJECT-ID>/
GEN-XX/PROJECTS/<PROJECT-ID>/
CROSS-GEN/PROJECTS/<PROJECT-ID>/

GEN-XX/<GAME-ID>/COMPARES/<COMPARE-ID>/
GEN-XX/COMPARES/<COMPARE-ID>/
CROSS-GEN/COMPARES/<COMPARE-ID>/
```

The same superset rule applies at project, compare, reference and shared coordinates.

## Pair-sync invariant

1. Tsubaki is the archival source for the complete non-ROM project corpus.
2. Sakurai is a curated view of research/control artifacts.
3. Every Sakurai path must have a Tsubaki counterpart at the same semantic coordinate and equivalent content unless a manifest explicitly records a generated-format transformation.
4. New work is written to Tsubaki first or in the same atomic work cycle; eligible knowledge artifacts are mirrored to Sakurai.
5. A Tsubaki-only artifact is valid. A Sakurai-only non-ROM artifact is a synchronization defect.
6. Hash catalogs record equality; do not delete provenance merely because two artifacts are identical.

## ROM exclusion

Forbidden in both repositories: complete original ROM images and complete modified/rebuilt/playable ROM images.

Allowed and expected in Tsubaki: every non-ROM artifact, including extracted ROM-derived resources and byte ranges when they are legitimate project artifacts rather than a disguised complete ROM image.

See `INFRA/POLICY/ROM-BINARY-EXCLUSION.md` and `INFRA/POLICY/PAIR-SYNC.md`.
