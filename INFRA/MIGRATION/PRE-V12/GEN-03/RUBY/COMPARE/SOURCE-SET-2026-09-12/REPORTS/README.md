# Ruby 13-ROM comparison

This v6 comparison owns relationships among the 13 supplied Ruby releases. Release/dump facts remain in each `SOURCE/GBA/CART/<RELEASE-ID>` leaf.

Highlights:
- Japanese source is 8 MiB; the supplied international/debug sources are 16 MiB.
- Startup layout A: AXVJ/AXVE. Startup layout B: AXVD/AXVF/AXVI/AXVS.
- AXVE-HV1→HV2 and DE/FR/IT/ES retail HV0→HV1 each change only four bytes in the compared images.
- German debug is a materially distinct build, not an ordinary revision.
