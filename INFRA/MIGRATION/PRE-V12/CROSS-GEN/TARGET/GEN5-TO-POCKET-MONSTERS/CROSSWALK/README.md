# CROSSWALK

Each crosswalk maps a Generation V source element to one or more target implementations without deleting the target's original content.

Canonical domains: `POKEMON`, `FORMS`, `TYPES`, `ABILITIES`, `MOVES`, `ITEMS`, `EVOLUTION`, `BATTLE`, `ENCOUNTERS`, `TRAINERS`, `NPC`, `MAPS`, `EVENTS`, `TEXT`, `GRAPHICS`, `ANIMATION`, `AUDIO`, `UI`, `SAVE`, `COMMUNICATION`, `TIME-DATE-SEASONS`, `UNUSED`.

Every record should retain source game/release, target release, original target behavior, Gen V behavior, conflict class, integration rule, implementation status and verification status.

Project policy order: preserve → coexist → integrate → expand → conditional branch.
