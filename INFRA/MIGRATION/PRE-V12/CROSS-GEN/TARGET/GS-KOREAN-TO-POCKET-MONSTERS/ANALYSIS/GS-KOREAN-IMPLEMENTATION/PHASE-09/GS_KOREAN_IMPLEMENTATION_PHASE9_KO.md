# GS Korean 구현 분석 9단계: 도구명 256슬롯 현행화 대조

- 분석일: 2026-09-12
- 대상: 한국 정식판 『포켓몬스터 금』·『포켓몬스터 은』
- 원본 범위: Bank `0x6C` 도구명 256슬롯과 5단계 Bank `0x6E` 설명 연결표
- 작업 성격: 명칭 대조·슬롯 분류·인코딩 가능성 검사
- ROM 출력: 없음

## 결론

도구명 256슬롯을 의미와 실제 출력 용도에 따라 전부 분류했다.

| 분류 | 수량 | 처리 원칙 |
|---|---:|---|
| 실제 명칭 도구 | 164 | 현행 한국어 데이터 또는 최종 한국 공식 출현명과 대조 |
| 기술머신·비전머신 | 57 | Gen II의 `기술머신01`·`비전머신01` 형식 유지 |
| 미사용·내부 슬롯 | 35 | `?`·`<?>`를 임의 도구명으로 바꾸지 않고 보존 |
| 합계 | 256 | 전 슬롯 추적 완료 |

실제 명칭 164개 가운데 147개는 PKHeX와 PokéAPI의 현행 한국어 데이터가 일치했다. 나머지 17개는 현행 데이터 행이 없는 단종·세대 고유 도구이므로 GS Korean의 마지막 공식 한국어 명칭을 보존하거나, 별도의 교정·신규 번역 상태를 명시했다.

두 데이터 원천은 공식 출판물 자체가 아니라 공식 현지화 데이터를 정리한 보조 미러다. 그러므로 147개도 `CURRENT_LOCALIZATION_DATA_CONSENSUS`로 기록했으며 `DIRECT_OFFICIAL_SOURCE_VERIFIED`라고 과장하지 않았다. 최종 출시 전에는 확인 가능한 1차 공식 자료를 추가 연결한다.

## 변경 집계

| 항목 | 수량 |
|---|---:|
| 변경 없음 | 141 |
| 변경 대상 | 115 |
| 띄어쓰기 정규화 | 95 |
| 후속 세대 명칭으로 계승 | 10 |
| 개명·표기 교정 | 9 |
| 현행 공식 행이 없는 신규 번역안 | 1 |

모든 최종 후보는 GS Korean 문자표로 인코딩할 수 있다. 전체 표는 종단자를 포함하여 2,465바이트에서 2,340바이트로 125바이트 감소한다. 가장 긴 최종 후보의 문자열 본체는 16바이트다.

## Generation II 나무열매 계승명

Generation II의 기능상 대응 관계가 후속 세대에서 정식 명칭으로 계승된 10개는 다음과 같이 분리 기록했다.

| ID | 기존 | 계승 명칭 |
|---:|---|---|
| `0x4A` | 해독열매 | 복슝열매 |
| `0x4E` | 마비치료열매 | 버치열매 |
| `0x4F` | 불탄 나무열매 | 배리열매 |
| `0x50` | 얼은 나무열매 | 복분열매 |
| `0x53` | 쓴맛 나무열매 | 시몬열매 |
| `0x54` | 박하열매 | 유루열매 |
| `0x6D` | 기적의 열매 | 리샘열매 |
| `0x96` | 이상한 나무열매 | 과사열매 |
| `0xAD` | 나무열매 | 오랭열매 |
| `0xAE` | 황금열매 | 자뭉열매 |

이들은 단순 띄어쓰기 변경과 섞지 않고 `GENERATION_SUCCESSOR_NAME`으로 관리했다. 효과 설명은 5단계 원문을 그대로 연결해 두었으며, 후속 세대 효과가 Gen II에 존재했던 것처럼 덮어쓰지 않는다.

## 단종·고유 도구 처리

- `핑크빛 리본`, `GS볼`, `파괴의 유전자`, `나무상자`, `오동나무상자`는 현행 한국어 미러 행이 없어 GS Korean 공식 명칭을 보존했다.
- 구형 메일 10종은 포켓몬 도구명 표기 관례에 맞춘 붙여쓰기 후보로 분리했다.
- `물방울 리본`은 원문 `POLKADOT BOW`의 의미를 살린 `물방울무늬 리본`을 신규 번역안으로 기록했다. 공식 명칭처럼 확정하지 않았으며 추가 검수가 필요하다.
- 미사용·내부 슬롯 35개에는 추정 명칭이나 후대 도구를 배정하지 않았다.
