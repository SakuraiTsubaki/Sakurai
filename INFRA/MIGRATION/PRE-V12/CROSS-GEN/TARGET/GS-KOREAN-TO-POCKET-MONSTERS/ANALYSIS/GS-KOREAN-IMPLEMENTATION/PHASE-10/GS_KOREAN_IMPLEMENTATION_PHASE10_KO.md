# GS Korean 구현 분석 10단계

## 목적

9단계에서 확정한 도구명 후보 256개를 GS Korean의 문자 체계로 다시 인코딩하고, 실제 ROM에 쓰지 않은 메모리상 재빌드로 고정 영역·포인터·UI 길이의 정적 안전성을 검증한다.

이 단계의 바이너리는 완성 ROM이나 배포 패치가 아니다. `item_name_region_candidate.bin`은 향후 통합 작업에 사용할 **승인 전 후보 삽입 데이터**이며 상태는 `CANDIDATE_NOT_FINAL`이다.

## 입력과 보존 원칙

- 기술 원본: 한국 정식판 포켓몬스터 금·은
- 언어 입력: 9단계 `item_name_current_comparison.csv`의 최신 명칭 후보
- 원본 ROM: 읽기 전용
- 생성 ROM: 없음
- 검증 방식: 원본 바이트를 메모리에서 복제한 뒤 해당 고정 구간만 후보 데이터로 교체

## 재빌드 결과

| 항목 | 결과 |
|---|---:|
| 도구명 슬롯 | 256개 |
| 원본 표 크기 | 2,465바이트 |
| 후보 표 크기 | 2,340바이트 |
| 크기 변화 | -125바이트 |
| 고정 교체 구간 | Bank `0x6C`, CPU `0x4000–0x49A1` |
| 후보 데이터 전체 크기 | 2,465바이트 |
| 표 뒤 0 채움 | 125바이트 |
| 후보 SHA-256 | `0a3c5e5579bc7185d39bb9c60a26b9b45ebe8cf1d1c5e1f8e8b3e7acfbc1889f` |

후보 표의 끝은 CPU `0x4924`다. 남은 `0x4924–0x49A1`을 0으로 채워 다음 표인 트레이너 분류명이 계속 CPU `0x49A1`에서 시작하도록 했다. 따라서 도구명 포인터와 뒤쪽 표 포인터를 수정할 필요가 없다.

## 이름 조회 구조

한국판 금·은에서 다음 위치와 바이트가 서로 동일함을 확인했다.

| 심볼 | Bank | CPU 주소 | 길이 | 역할 |
|---|---:|---:|---:|---|
| `NamesPointers` | `0x00` | `0x35C3` | 24바이트 | 이름 표 뱅크·주소 선택 |
| `GetName` | `0x00` | `0x35DB` | 78바이트 | 이름을 21바이트 버퍼로 복사 |
| `GetNthString` | `0x00` | `0x3629` | 15바이트 | 종료 코드 `0x50`을 기준으로 n번째 문자열 검색 |
| `GetItemName` | `0x00` | `0x368A` | 31바이트 | 일반 도구명 및 기술머신·비전머신 이름 분기 |

도구명 표의 포인터는 Bank `0x6C`, CPU `0x4000`이고, 다음 트레이너 분류명 표는 Bank `0x6C`, CPU `0x49A1`이다. 메모리상 재빌드 뒤에도 두 위치는 변하지 않는다.

## UI 및 버퍼 감사

| 검사 | 결과 |
|---|---:|
| 원본 최대 표시 폭 | 8타일 |
| 후보 최대 표시 폭 | 8타일 |
| 8열 가방 목록 초과 | 0개 |
| 8열 상점 목록 초과 | 0개 |
| 21바이트 이름 버퍼 초과 | 0개 |
| 표시 폭이 늘어난 이름 | 2개 |

표시 폭이 늘어난 항목은 `정기권 → 리니어패스`(3→5타일), `물방울 리본 → 물방울무늬 리본`(6→8타일)이다. 후보 중 8타일 이름은 `벌레회피스프레이`와 `물방울무늬 리본`이며, 종료 코드까지 포함한 최대 인코딩 길이는 각각 17바이트와 16바이트다. 모두 21바이트 복사 버퍼 안에 들어간다.

정적 길이 검사는 통과했지만 실제 글자 출력, 커서, 스크롤, 전투 메시지 결합은 에뮬레이터 런타임 검사가 필요하다.

## 통합 시 적용 규칙

1. 원본 ROM의 SHA-1이 매니페스트 허용 목록과 일치하는지 확인한다.
2. 후보 데이터 2,465바이트를 Bank `0x6C`의 오프셋 `0x0000–0x09A1`, 즉 CPU `0x4000–0x49A1`에 완전 교체한다.
3. 포인터는 수정하지 않는다.
4. 용어 승인이 끝나기 전에는 최종 패치로 승격하지 않는다.
5. 가방의 도구·볼·중요한 물건, 상점의 구매·판매, 전투 도구 메시지, 지닌 도구와 상태 화면, 기술머신·비전머신 동적 이름을 런타임 검사한다.

## 판정

도구명 후보 256개의 인코딩, 고정 영역 배치, 조회 루틴, 8열 목록 폭, 21바이트 버퍼는 정적으로 안전하다. 금·은의 메모리상 재빌드 Bank `0x6C` 해시도 서로 일치한다. 다만 이 결과는 삽입 후보이며, 실제 ROM 통합과 에뮬레이터 검증 전에는 최종본으로 간주하지 않는다.

다음 단계는 CPU `0x49A1`에서 시작하는 트레이너 분류명 표의 최신 공식 명칭 대조다.
