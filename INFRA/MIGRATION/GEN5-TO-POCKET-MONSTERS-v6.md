# Generation V → ポケットモンスター v6 migration

Canonical project root: `PROJECTS/CROSS-GEN/GEN5-TO-POCKET-MONSTERS/`.

The project is cross-generation because Generation V sources feed Generation II and Generation III target implementations. `PROJECTS/GEN-05/GEN5-TO-POCKET-MONSTERS/` is therefore not a valid v6 owner and is removed from the live canonical tree after this migration.

Gen II supplied targets were re-keyed to directly verified native tokens where available: Gold `AAUK-HV0`, Silver `AAXK-HV0`, Crystal JP `BXTJ-HV0`, Crystal EN Rev A `BYTE-HV1`. Existing weaker market/language paths may remain temporarily elsewhere only as migration inputs for other projects; they are not canonical identities for this project.

ROM binaries are never committed. Only identity, hashes, structure, transformation metadata, tools, verification evidence, and project outputs are routed.
