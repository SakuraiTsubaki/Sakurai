# Silver ROM routing

**Sakurai** owns release/dump identity, hashes, header/checksum observations, bank comparisons, reverse-engineering facts, reports and verification.

**Tsubaki** owns production routing, converters, derived production assets, implementation source, patches, builds and build verification. It references Sakurai release/dump identities instead of duplicating ROM binaries.

Original ROM binaries remain local read-only inputs and are never committed. Raw copyrighted assets are not promoted merely because they can be extracted.
