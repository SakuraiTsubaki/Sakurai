# Pokémon Emerald v6 migration

This temporary migration project stages the owner-by-owner move from the quarantined pre-v6 Emerald trees into canonical v6 paths. It is not a new gameplay project. The authoritative source path is `LIBRARY/GEN-03/EMERALD/SOURCE/GBA/CART/<RELEASE-ID>/`; same-game research lives under `LIBRARY/GEN-03/EMERALD/COMPARE/<COMPARISON-ID>/`. Original ROM binaries are never committed.
