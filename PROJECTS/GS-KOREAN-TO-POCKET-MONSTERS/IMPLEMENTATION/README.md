# Research-side implementation specifications

This section owns target maps and implementation specifications that explain how verified Korean mechanisms are adapted to each Japanese or English source release.

It may contain pointer plans, bank-allocation plans, text-engine changes, UI layout specifications, SRAM/name-handling plans, and target-specific address maps.

Production-ready insertion tables, converted fonts/graphics, build inputs, patches, and generated binary resources belong in the matching Tsubaki project tree.

No target may be treated as a fabricated official Korean `LIBRARY` release. A new Korean localization is a project output referencing its real source release.
