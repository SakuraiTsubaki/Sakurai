# Translation crosswalk ownership

Crosswalk data is project-owned research and must preserve source-region differences.

- Japanese releases are mapped directly from Japanese source text to Korean.
- English releases are mapped directly from English source text to Korean.
- A matching event/string in JP and EN does not imply one shared Korean translation unless the source text and context are verified equivalent.
- Current official Korean Pokémon terminology is the naming reference layer, not a replacement translation source.
- Korean Gold/Silver legacy strings may be recorded as implementation/history evidence but are not authoritative source text for other releases.

Recommended domain children: `POKEMON`, `MOVES`, `ITEMS`, `TRAINERS`, `LOCATIONS`, `SYSTEM`, `TEXT`, `UI`, `POKEDEX`.
