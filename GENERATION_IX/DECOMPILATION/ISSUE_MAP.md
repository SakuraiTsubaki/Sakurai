# Generation IX Decompilation Issue Map

The title repositories use issue tracking for evidence-bearing execution. This document defines the active issue families to prevent any research axis from disappearing as the project grows.

## Per-title issue families

Each title repository should maintain active tracking for:

- Target identity / revision inventory
- Filesystem / structural mapping
- Executable / function reconstruction
- Containers / serialization
- Pokémon / forms
- Moves
- Abilities
- Items / materials
- Battle mechanics
- Maps / world / collision
- Encounters
- NPCs / trainers
- Scripts / events / quests / flags
- Graphics / animation
- UI
- Text / localization
- Audio
- Online / communication
- Events / distributions
- DLC / update differences
- Pokémon HOME linkage
- Unused / removed data
- Bugs / patch behavior
- Rebuild / verification

## Cross-title issue families

Central Generation IX analysis additionally tracks:

- Scarlet ↔ Violet same-revision common/different files
- Scarlet ↔ Violet semantic version differences
- Shared Generation IX data models versus title-specific implementations
- Pokémon Legends: Z-A divergences from Scarlet/Violet
- DLC-boundary comparisons
- Cross-title Pokémon / move / item parameter changes
- HOME / transfer compatibility changes
- Switch ↔ Switch 2 behavior and data differences

## Status rule

An issue may be blocked by missing verified local input, but it remains active scope. Do not close a workstream because representative samples were completed.
