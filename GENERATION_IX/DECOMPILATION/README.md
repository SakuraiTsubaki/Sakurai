# Generation IX Decompilation

This directory is the central coordination layer for the complete Generation IX decompilation project.

## Active repositories

- `SakuraiTsubaki/PocketMonsters-Scarlet-Decompilation`
- `SakuraiTsubaki/PocketMonsters-Violet-Decompilation`
- `SakuraiTsubaki/PokemonLegends-Z-A-Decompilation`

## Documents

- `MASTER_TRACKER.md` — title/content/workstream state
- `WORKSTREAMS.md` — complete research and reconstruction axes
- `STATUS.md` — current execution layer and blockers
- `SOURCES.md` — first-party public boundary sources
- `ISSUE_MAP.md` — required issue families
- `scope.json` — machine-readable complete scope

## Operating rule

Work proceeds in parallel. Scarlet and Violet are aggressively compared but never merged into one undifferentiated title. Pokémon Legends: Z-A remains an independent implementation track. Historical revisions, DLC states, event/live content, HOME linkage, unused data and patch-specific behavior are retained as first-class research dimensions.

No retail ROM/game image, update package, console key or raw proprietary dump belongs in GitHub. Everything else that is permissible and useful for reproducible research—analysis, tools, schemas, manifests, hashes, reconstructed source, tests, patches and documentation—is intended to be versioned.
