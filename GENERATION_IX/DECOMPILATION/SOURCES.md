## Research policy

1. Public first-party sources define names, release/update boundaries and officially described behavior.
2. Repository hashes, binary layouts, symbols, resource paths and implementation details are not inferred from marketing/support prose.
3. Secondary sources may be added for gaps, but must be labeled separately from first-party evidence.
4. If first-party documentation changes, preserve the date/context of any historical conclusion rather than silently rewriting the record.
