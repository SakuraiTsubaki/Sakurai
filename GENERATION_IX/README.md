# Generation IX

Generation IX is the umbrella research and reconstruction workspace for the ninth generation of Pokémon games covered by this project.

## Active primary titles

- Pokémon Scarlet
- Pokémon Violet
- Pokémon Legends: Z-A

## First-party expansion and linked-content scope

### Pokémon Scarlet / Pokémon Violet

- Base game and all verified software revisions
- Version-exclusive content and version-specific data
- The Hidden Treasure of Area Zero
  - Part 1: The Teal Mask
  - Part 2: The Indigo Disk
- Epilogue / additional story-event content
- Tera Raid Battles, including limited-time event raids
- Mystery Gift and official distributions
- Ranked / official battle-rule data where it affects game behavior or data
- Pokémon HOME compatibility and transfer-related data
- Nintendo Switch / Nintendo Switch 2 behavior differences where observable

### Pokémon Legends: Z-A

- Base game and all verified software revisions
- Nintendo Switch and Nintendo Switch 2 Edition differences where observable
- Mega Dimension DLC
- Mega Evolution, including title-specific and DLC-specific implementations
- Lumiose City, Wild Zones, Battle Zones, Z-A Royale, quests, movement, capture and real-time battle systems
- Z-A Battle Club / online battle behavior
- Official distributions and event content
- Pokémon HOME compatibility and transfer-related data

## Global workstreams

Every title is tracked across these independent workstreams. Similar names do not imply identical implementation between titles.

1. Executable / code reconstruction
2. Container, archive and filesystem formats
3. Pokémon species / forms / parameters
4. Moves
5. Abilities
6. Items / key items / materials / TMs
7. Maps / world / collision / placement
8. NPCs / trainers / battle parties
9. Scripts / events / quests / flags
10. Battle systems and title-specific mechanics
11. Graphics / models / textures / animation / UI
12. Audio / music / sound effects
13. Text / localization / message resources
14. Online / communication / distributions / live-event data
15. DLC / update / version-difference analysis
16. Pokémon HOME and external-link behavior
17. Unused / removed / legacy data
18. Bugs / glitches / patch-history behavior
19. Rebuild / validation / reproducibility tooling

## Evidence rule

Official documentation defines the public content boundary, but implementation claims require observed evidence from verified local research material. Guesses remain explicitly unverified. Historical revisions are preserved rather than overwritten by current data.

## Repository boundary

Retail game images, update packages, console keys and raw proprietary dumps are not committed. Analysis, documentation, hashes, manifests, reconstructed source, schemas, tools, tests, patches and permissible derived/recreated assets are tracked in GitHub.

See `DECOMPILATION/MASTER_TRACKER.md` for the active decompilation work matrix.
