# Generation III disassembly v12 research consolidation

Status: migrated and verified on the migration branch.

The curated research/control material from the five standalone Generation III disassembly repositories now lives at the same canonical semantic coordinates used by Tsubaki.

| Game | Canonical project path |
|---|---|
| Ruby | `GEN-03/RUBY/PROJECTS/RUBY-DISASSEMBLY/` |
| Sapphire | `GEN-03/SAPPHIRE/PROJECTS/SAPPHIRE-DISASSEMBLY/` |
| Emerald | `GEN-03/EMERALD/PROJECTS/EMERALD-DISASSEMBLY/` |
| FireRed | `GEN-03/FIRERED/PROJECTS/FIRERED-DISASSEMBLY/` |
| LeafGreen | `GEN-03/LEAFGREEN/PROJECTS/LEAFGREEN-DISASSEMBLY/` |

Sakurai retains the curated research/control subset such as analysis, documentation, manifests, symbol maps, reports, research tooling and verification material. Tsubaki owns the complete eligible non-ROM corpus at the same coordinates. Each project contains `MIGRATION-SOURCE.md` with the source repository and exact source commit used for migration.

The standalone repositories are retained as provenance/migration sources; they are no longer the canonical location for project work.
