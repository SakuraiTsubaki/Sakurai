# Pokémon Ruby — v6 canonical source library

Canonical research root for the 13 supplied Pokémon Ruby GBA images.

- Canonical release path: `SOURCE/GBA/CART/<RELEASE-ID>/`
- Exact observed dump: `<RELEASE-ID>/DUMPS/<DUMP-ID>/`
- Same-game comparisons: `COMPARE/<COMPARISON-ID>/`
- Original `.gba` binaries are local/read-only inputs and are never committed.
- Language/market metadata lives in manifests; the path uses the native GBA game code + header version.
- German retail `AXVD-HV0` and German debug `AXVD-HV0-DEBUG` are distinct build identities despite sharing game code/header version.

Current supplied set: 13 exact dumps / 13 release identities.
