## Structural comparison

Both images expose 484 FAT/file-ID entries: 237 ARM9 overlay file IDs plus 247 named NitroFS files. Comparing SHA-256 at identical file IDs produced:

- 299 identical entries;
- 185 different entries.

ARM7 is byte-identical between the two observed images; ARM9 differs. Full per-file and per-overlay indexes are generated by the reproducible inventory tool and belong under the source `NATIVE/INDEXES/` and comparison `INDEXES/` trees.

## Preservation status

These SweeTnDs hashes are retained as **observed dump identities**, not promoted to clean-reference release hashes. Public preservation/decompilation references use different SHA-1 values for clean USA/Europe v1.0 images (Black `26ad0b9967aa279c4a266ee69f52b9b2332399a5`, White `bc696a0dfb448c7b3a8a206f0f8214411a039208`). Dump-bound data therefore remains marked for clean-reference revalidation before release-level promotion.
