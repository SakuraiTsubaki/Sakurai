# Pocket Monsters Crystal Japanese -> Korean title

Current approved title: **포켓몬스터 크리스탈**.

## Final visual rule

- Common `포켓몬스터` artwork is taken from the official Korean Gold/Silver title system.
- `크`, `리`, `스`, `탈` come from the GS Korean Hangul font implementation.
- Use approved **B** treatment: exterior-only outline plus top/left highlight.
- Do **not** expand the title footprint to the right.
- Keep the X envelope aligned to the Korean Gold/Silver version-name side.
- Use additional Y-axis space for the four-syllable name instead of crushing the glyphs horizontally.
- Current layout is 2x2: `크 리 / 스 탈`.
