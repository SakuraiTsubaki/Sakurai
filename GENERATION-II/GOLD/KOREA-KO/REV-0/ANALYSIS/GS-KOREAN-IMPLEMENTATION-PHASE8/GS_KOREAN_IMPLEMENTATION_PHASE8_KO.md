# GS Korean 구현 분석 8단계: 기술명 조회·UI 길이·재빌드 드라이런

- 분석일: 2026-09-11
- 대상: 한국 정식판 『포켓몬스터 금』·『포켓몬스터 은』
- 선행 자료: 7단계 기술명 현행화 비교표 251건
- 작업 성격: 읽기 전용 분석 및 메모리상 재빌드 검증
- ROM 출력: 없음

## 결론

한국판 금·은의 기술명은 Bank `0x6C`, CPU 주소 `0x564A`부터 기술 ID 순서대로 저장되어 있다. 기술마다 별도의 포인터가 있는 구조가 아니라 `GetNthString`이 문자열 종단자 `0x50`을 차례로 세어 원하는 이름을 찾는다.

따라서 최종 통합 삽입 시 다음 절차만 필요하다.

1. 승인된 기술명 251개를 기술 ID 순서로 인코딩한다.
2. 각 이름 뒤에 종단자 `0x50`을 붙인다.
3. Bank `0x6C:0x564A`의 기존 기술명 표를 교체한다.
4. 표 뒤의 남는 Bank 영역을 0으로 채운다.
5. 기존 `NamesPointers` 항목 `Bank 0x6C / CPU 0x564A`는 유지한다.

기술별 포인터 수정은 필요하지 않다. 실제 ROM 반영은 다른 번역·UI·포인터 변경과 함께 별도 작업본에 일괄 적용한다.

## 조회 루틴 근거

금·은 양쪽 ROM에서 다음 바이트열을 독립적으로 확인했으며 모두 동일하다.

| 구조 | Bank | CPU/파일 주소 | 기능 |
|---|---:|---:|---|
| `NamesPointers` | `0x00` | `0x35C3` | 기술명 표를 `0x6C:0x564A`로 지정 |
| `GetName` | `0x00` | `0x35DB` | 이름 종류와 ID를 받아 문자열 버퍼로 복사 |
| `GetNthString` | `0x00` | `0x3629` | `0x50` 종단자를 세어 N번째 문자열 탐색 |
| `GetMoveName` | `0x00` | `0x3726` | 이름 종류 2로 `GetName` 호출 |

`GetName`의 복사 길이는 21바이트다. 현행 기술명 가운데 가장 긴 인코딩 결과도 종단자를 포함해 15바이트이므로 251개 모두 이 버퍼 한계 안에 들어간다.

구조 해석에는 pret의 `pokegold` 소스를 교차 참고했지만, 주소·바이트열·동작 판정은 한국판 금·은 ROM 자체를 기준으로 확정했다.

## 재빌드 드라이런

ROM 파일을 수정하거나 출력하지 않고, 메모리에서 Bank `0x6C`만 재구성한 뒤 동일 디코더로 251개 기술명을 다시 읽어 원본 비교표와 일치하는지 확인했다.

| 항목 | 기존 | 현행 기술명 재빌드 | 변화 |
|---|---:|---:|---:|
| 표 시작 | `0x564A` | `0x564A` | 없음 |
| 표 끝(배타적) | `0x5EE1` | `0x5EC4` | 29바이트 앞당김 |
| 표 크기 | 2,199바이트 | 2,170바이트 | -29바이트 |
| 뒤쪽 0 채움 영역 | 8,479바이트 | 8,508바이트 | +29바이트 |
| Bank SHA-256 | `80ddef8b…8416` | `b4bfc4a0…53fc` | 금·은 동일 |

드라이런 결과 금·은의 재구성 Bank는 완전히 동일하며, 251개 전부 현행 기술명으로 정상 역디코딩되었다.

## UI 길이 감사

- 기존 최장 표시 폭: 7타일
- 현행 최장 표시 폭: 7타일
- 기존보다 길어진 이름: 5개
- 기존 게임 전체 최장 폭 7타일을 넘는 이름: 0개
- 21바이트 이름 버퍼를 넘는 이름: 0개

길어진 이름은 다음과 같다.

| ID | 기존 | 현행 | 표시 타일 변화 |
|---:|---|---|---:|
| 67 | 잡치기 | 안다리걸기 | +2 |
| 140 | 알던지기 | 구슬던지기 | +1 |
| 168 | 도둑 | 도둑질 | +1 |
| 196 | 얼다바람 | 얼어붙은바람 | +2 |
| 227 | 앵콜 | 앙코르 | +1 |

정적 한계 감사에서는 모두 안전하다. 다만 이는 모든 실제 화면을 에뮬레이터에서 통과시켰다는 뜻은 아니다. 최종 통합 ROM이 만들어지면 전투 기술 선택, 기술머신, 상태 화면, 기술 삭제·습득 등 실제 호출 화면을 별도로 회귀 시험해야 한다.
