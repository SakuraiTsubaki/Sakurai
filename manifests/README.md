# Manifests

Sakurai manifests record stable identity, origin, provenance, relationships, and verification for research/control records.

Useful fields include aggregate record ID; originating repository/project; release/build/version/revision/region/language; artifact or source locator; commit/hash evidence; related Tsubaki record; relationship type; tool/method; and verification state.

Do not invent unknown values. See `example.asset-manifest.json` for a minimal example.
