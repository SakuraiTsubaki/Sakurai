# Static source rule

BW stores dedicated static Pokémon battle NCGR members separately from multipart animated parts.

For Generation III baseline static insertion, use the dedicated static NCGR roles (`+0/+1/+9/+10` within a resolved standard block) as the authoritative source. Do not freeze an arbitrary animation frame and substitute it for the static sprite.

The multipart animation data remains a mandatory preservation track in Sakurai and is not discarded.
