# Source-selection rule

The canonical source is the closest verifiable official or preservation-grade source available for the specific asset.

For the currently supplied BW EUR battle-sprite set, the directly decoded `/a/0/0/4` ROM data is available and therefore has priority over web previews, mirrors, screenshots, and external PNG packs.

This priority is contextual, not a universal ROM requirement. If direct game data is unavailable for another generation/title/asset, work continues from the best verifiable official or preservation-grade source and records its limitations explicitly.
